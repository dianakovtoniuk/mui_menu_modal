# MUI Demos

Small demos built with Material UI.

## Demos

- **Menu**: dropdown menu with `Menu` and `MenuItem`, anchored to the button that opened it via `anchorEl`.
- **Modal**: basic `Modal` opened and closed with a button.

## Stack

- React 18
- Material UI 5 (`@mui/material`, Emotion)
- Create React App

## Getting started

```bash
npm install
npm start
```

The app runs at http://localhost:3000.
